# 시연 준비 (Pleos Connect 에뮬레이터)

2026-11-13 작성. 아래 순서를 이 PC에서 직접 따라 해 확인했다. 확인하지 못한 단계는 **[미확인]** 으로 표시했다.

## 1. 에뮬레이터 켜기 (GPU 모드)
- 파일 탐색기에서 `DropMate\tools\start-pleos-mouse.cmd` 를 실행한다.
  - AVD `Pleos_Connect_v2.1.0` 을 마우스 입력 설정(VirtioTablet)으로 켠다. 2026-11-13 실제로 켜서 약 30초 만에 부팅됐다.
- 그래픽 모드: Android Studio > Device Manager > `Pleos_Connect_v2.1.0` > 편집(연필) > Graphics 를 **Hardware - GLES 2.0** 으로 두면 된다. 이 AVD는 이미 Hardware(GPU)로 설정돼 있다(README 기준).
  - 이번에는 설정 화면을 열어 다시 확인하지 않았다 **[미확인]**.

## 2. 에뮬레이터 위치를 출발지로 맞추기
에뮬레이터 기본 위치는 미국(Mountain View)이다. 그대로 두면 출발지가 미국으로 잡히고 '내 위치로' 버튼도 미국으로 간다.

방법 A — 명령어(확인함). **경도, 위도 순서**이다(위도가 먼저 아님). 서문여고 예시:
```bash
adb emu geo fix 126.985450 37.489485
```
- `adb` 는 `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe` 에 있다.

방법 B — 에뮬레이터 화면: 오른쪽 도구 막대 `…`(Extended controls) > Location > 검색창에 장소 입력 또는 위도·경도 입력 > **Set Location**. **[미확인]**(이번에는 방법 A만 실제로 써 봤다)

## 3. APK 설치
1. 키 파일 `app\src\main\assets\api.properties` 에 TMAP·카카오 키가 있어야 한다. 키 내용은 이 문서에 적지 않는다.
2. 빌드(JDK 21):
   ```bash
   gradlew.bat -PpleosSdk=true :app:assembleDebug
   ```
3. 설치:
   ```bash
   adb install -r app\build\outputs\apk\debug\app-debug.apk
   ```
- 2026-11-13 같은 명령으로 빌드·설치했다.
- 처음 실행하면 Pleos 위치 권한을 묻는다 → **허용**.

## 4. 시연 순서
1. 에뮬레이터 앱 목록에서 DropMate 실행 → 출발지가 '차량 현재 위치 (Pleos)'로 잡혔는지 확인(2단계에서 정한 곳)
2. 운전자 목적지·동승자 목적지 입력(카카오 검색) → 계산
   - TMAP 약 12~20회 사용. 로컬 예산은 `api.properties` 의 `tmap.budget`.
3. 결과 카드 확인
   - 1위 하차점(예: '아크로리버파크 게이트1 앞'), 운전자 우회, 동승자 절약
   - 아래 줄 '현재 교통 기준 HH:mm 조회'
4. 지도를 손으로 옮긴 뒤 오른쪽 위 남색 원형 '내 위치로' 버튼 → 차 위치로 돌아오는지 확인
5. '하차 후 경로 보기' → '이 경로로 안내 시작' → 안내 화면
   - 안내 중에 지도를 옮기면 오른쪽 가운데에 '내 위치로' 버튼이 나타난다. 누르면 다시 차를 따라간다.
   - 오른쪽 위 '실제 위치/모의 주행'으로 모드를 바꾼다. 시연은 **모의 주행** 권장(차가 경로를 따라 움직임).

## 5. 주의
- 모든 시간은 **조회 시점의 실시간 TMAP 교통 기준**이다. 같은 경로도 밤·아침에 결과가 다르다.
  - 예: 서문여고→아크로 동승자 절약이 밤 16~18분, 아침 10분.
  - 시연과 리허설은 같은 시간대에 하는 게 좋다.
- 실제 주행으로는 아직 검증하지 않았다.
- '실제 위치' 모드로 안내를 시작했는데 에뮬레이터 위치가 경로와 멀면, 경로 이탈로 보고 **자동 재탐색(TMAP 호출)** 이 일어난다. 시연은 모의 주행으로 하거나, 2단계에서 출발지와 같은 위치로 맞춰 두세요.
- 디버그 APK 안에는 `api.properties` 키가 들어 있으니 외부로 배포하지 마세요.
