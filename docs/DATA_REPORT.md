### 앱 자산으로 만든 범위
- 범위: 위도 37.0~38.0, 경도 126.5~127.6 (수도권). 정류장 54,133 / 고유 정차 패턴 6,213 (노선+정차순서 단위, 범위 밖 정류장은 잘라냄)
- 철도역 793곳, 노선: 서울1~9호선, 신림선, 신분당선, 수인분당선, 경의중앙선, 공항철도, GTX-A 등 24개 포함
- 사용 원칙: **사전 필터·조회 우선순위 전용**. GTFS 시간을 TMAP 시간에 더하거나 대체하지 않는다. 2025년 자료이므로 '연결 못 찾음'은 확정 제외가 아니라 판단 보류.

## 2. 보행 자료 — `DropMate_walk_reference_SHP_20261104.zip`

| 항목 | 확인 결과 |
|---|---|
| 형태 | 기존 2026-10-31 GeoJSON 선형 249개를 SHP로 변환한 참고본. **보행망 원본 그래프 아님**, 폴리곤·직선 버퍼 아님 |
| 범위 | 서울역 기준노드 1개, 관악구 남현동 노드 1개, 구파발·상일동·신림 보조망 내부. **버스정류장 보행권 없음** |
| 속도·단위 | 1.2 m/s 가정, 시간 등급(≤300초 / 300~600초). PLAN DEC-05(1.0 m/s·600m)와 속도 가정이 다름 |
| 방향 | 원본 방향 UNKNOWN 은 양방향 가정으로 이미 계산됨. 확인된 방향·제외 조건은 보존됨(자료 README) |
| 횡단·계단·출입 | 미반영(README 명시) |
| 재계산 | 원본 그래프가 없어 거리 기준 재계산 불가 |
| 출처 | 서울시 OA-21208 / OA-21213 (2020년 기준), 공공누리 제1유형으로 기존 기록 |

**판단:** 이 자료는 기본 사례(성동구 O → 관악구 D, 동작구 P) 경로의 접근점 보행거리 계산에 쓸 수 없다. 그래서 단방향 링크 양방향화(추가·유지 링크 수 집계)는 **수행하지 않았다** — 보행망 원본 그래프가 없음.
대신 앱은 (1) 직선거리 600m 초과만 증명된 확정 제외에 쓰고(보행망 거리 ≥ 직선거리), (2) 실제 접근 보행 600m 검사는 TMAP 대중교통 응답의 첫 WALK 구간 거리로 한다.
