## 현재 적용
1. 운전자 직행 O→D와 동승자 단독 O→P를 동일 t0 기준으로 비교한다.
2. 중간 하차(최대 6곳), D 하차, P 경유(동승자 목적지 입구 앞)를 요청당 최대 8개 평가한다. 기본 호출 상한은 14회다(2026-11-12 정확도 개선으로 3개·11회에서 변경).
3. 운전자 추가시간은 경유 D 도착−직행 D 도착으로 계산하며 min(900초, 직행 × 30%) 이하만 허용한다(2026-11-12 결정). 중간 하차는 정한 대로 직행 누적 구간시간을 사용하고 하차 60초를 포함한다.
4. 첫 탑승 지점 전 연속 도보의 공급자 소요시간이 600초 이하여야 한다. 문서의 1m/s·600m 환산 대신 이후 정한 실제 도보 10분 기준을 적용한다. 시간 누락은 0으로 통과시키지 않는다.
5. 동승자 최종 도착시각으로 선택한다. 분 반올림 순위는 11월 4일 확정값을 유지한다. 동률은 운전자 도착(같은 기준 직행이므로 추가시간 순서와 동일), 총 보행시간, 후보 ID 순이다. 환승 횟수로 빠른 경로를 탈락시키지 않는다.
6. 단독 대비 180초 이상 단축이면 추천, 0초 초과 180초 미만이면 비슷함, 0초 이하이면 이득 없음으로 표시한다.
7. TMAP 여정에 들어 있는 도보·대기를 다시 합산하지 않는다. 출발 위치는 하차점이다.
8. 각 요청의 decision_log.md에 선택·제외 근거, 후보별 시간, 비교 차이, 검증되지 않은 항목과 미조회 범위를 남긴다.
